# KOBA Platform

Single consolidated repository for the KOBA platform's active codebases. Each directory below is the real, current codebase — not an excerpt.

- `kobabot/` — Discord bot for Rust Console Edition (minigames, economy, Challenges/duels, KOBA Rank/Score progression, LFG, templates, backups).
- `koba-website/` — koba.games (player/business accounts, KOBAid, Xbox/PSN linking, admin dashboard, Rivals API bridge).
- `koba-rivals/` — standalone swipe-matchmaking app (developer portal, business/ad tooling, wired to kobabot's real player/server data).

No `.env` or secret files are included.
